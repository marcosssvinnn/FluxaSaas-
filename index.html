📧 E-mail Automático de Vistoria

Configure o EmailJS para enviar o relatório de vistoria automaticamente ao síndico/responsável. Crie uma conta gratuita em emailjs.com (200 e-mails/mês grátis), crie um serviço de e-mail e um template, então preencha abaixo.

Variáveis do template EmailJS:
{{to_email}} — e-mail do responsável  ·  {{to_name}} — nome do cliente  ·  {{empresa}} — nome da empresa
{{tecnico}} — técnico responsável  ·  {{mes_ref}} — mês de referência  ·  {{data_visita}} — data da vistoria
{{hora_checkin}} — entrada  ·  {{hora_checkout}} — saída  ·  {{duracao}} — tempo de visita
{{resumo}} — lista de equipamentos  ·  {{status_geral}} — resumo (✅ / ⚠️ / 🔴)
{{obs_geral}} — observações gerais  ·  {{link_relatorio}} — URL do PDF  ·  {{link_pdf}} — texto com link
📎 Para o e-mail sair com o PDF anexado:
1. No painel do Supabase → Storage → crie um bucket chamado vistorias-pdf (marcar como Public).
2. Vá em Storage → Policies e crie uma policy de INSERT para authenticated e SELECT para public.
3. No template do EmailJS, adicione o link: {{link_pdf}} — será um link direto para baixar o PDF gerado.
